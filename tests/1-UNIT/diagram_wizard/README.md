# DiagramWizard Unit Tests

This directory contains unit tests for the DiagramWizard feature components.

## Test Files

- `test_svg_validation.py` - SVG validation and testing utilities

## How to Run

From the project root:

```bash
# Run individual tests
python tests/1-UNIT/diagram_wizard/test_svg_validation.py
```

## Purpose

These unit tests focus on testing individual components and functions in isolation:
- SVG generation validation
- Helper function testing
- Data transformation validation
- Component-level error handling

Unit tests are designed to run quickly and test specific functionality without requiring full workflow integration.
