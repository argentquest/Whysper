  • 7-node LangGraph workflow (unchanged from original)
  • User-driven model selection at session start (NEW)
  • 4 AI models available (GPT-5, Grok, Claude, Gemini)
  • Model selection persists throughout session
  • Unified output schema across all models

KEY FEATURES:
  ✓ User selects preferred AI model before describing system
  ✓ Selected model used for ALL LLM calls in session
  ✓ 4 ANALYSE_CONFIRM versions (one per model)
  ✓ 4 CLARIFY_UNIVERSAL versions (one per model)
  ✓ Structurizr DSL as canonical representation (not D2)
  ✓ Dual representation guarantee (workspace + normalized clean)
  ✓ Clarity score 1-10 scale
  ✓ Ready threshold = clarity >= 8

DATA FLOW:
  User selects model
    → analyze_request (load model-specific ANALYSE_CONFIRM)
    → clarify_prompt (load model-specific CLARIFY_UNIVERSAL, loop until ready)
    → determine_diagram_type (auto-select: Mermaid/D2/PlantUML)
    → generate_code (generate diagram code)
    → validate_code + refine_code (fix errors, max 3 attempts)
    → render_diagram (output SVG)
