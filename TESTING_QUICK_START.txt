  🔍 WHAT TO EXPECT
================================================================================

When you render a Mermaid diagram:
  1. Component fetches provider info
  2. Code is validated via service
  3. Auto-fix applied if needed
  4. Backend renders via mermaidv1
  5. SVG returned with metadata
  6. Component shows provider name & time
  7. User sees rendered diagram

Expected console output:
  🎨 [MERMAID DIAGRAM] Provider info loaded: Mermaid v1
  🎨 [MERMAID DIAGRAM] Starting Mermaid diagram render via provider
  🎨 [MERMAID DIAGRAM] Validation result: { is_valid: true, ... }
  🎨 [MERMAID DIAGRAM] SVG rendered successfully via provider

Expected API calls:
  GET  /api/v1/diagram-provider/providers      (fetch provider info)
  POST /api/v1/diagram-provider/validate        (validate code)
  POST /api/v1/diagram-provider/render          (render diagram)

================================================================================
  🛠️ TROUBLESHOOTING
================================================================================

Diagram Not Rendering?
  → Check DevTools console for errors (F12)
  → Look for emoji prefix (🎨 or 🎯)
  → Check Network tab for API responses
  → Verify backend is running (http://localhost:8003)

Provider Not Found?
  → Run in console: diagramProviderService.listProviders()
  → Should show: mermaidv1 and d2v1
  → If not, check backend logs

API Errors?
  → Check Network tab for status codes
  → 404 = endpoint not found (backend issue)
  → 500 = server error (check backend logs)
  → 503 = provider unavailable (CLI not installed)

Slow Renders?
  → Check metadata.render_time in response
  → Expected: Mermaid 50-200ms, D2 100-500ms
  → Slower = LLM correction in progress
