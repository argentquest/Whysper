# Wells Fargo Brand Assets

This folder contains brand assets for the Wells Fargo theme.

## Asset Types

### Logos
- Place logo files here (SVG, PNG, etc.)
- Recommended formats: SVG for scalability, PNG for raster images

### Icons
- Custom icons specific to Wells Fargo branding
- Icon sets, favicons, etc.

### Images
- Brand imagery, backgrounds, patterns
- Marketing materials

## File Naming Convention

- Use lowercase with hyphens: `wf-logo-red.svg`
- Include dimensions for raster images: `wf-icon-48x48.png`
- Use descriptive names: `wf-background-pattern.svg`

## Usage

Import assets in your components:

```typescript
import wfLogo from '@/branding/WF/assets/wf-logo.svg';
```

Or reference in CSS:

```css
background-image: url('/branding/WF/assets/pattern.svg');
```
