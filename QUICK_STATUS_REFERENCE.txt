MESSAGE TYPES VISUAL GUIDE
─────────────────────────────────────────────────────────────────────────────

ℹ️  INFO MESSAGE (Blue)
    • Blue info icon
    • Auto-dismisses after 3 seconds
    • Used for: started, analyzing, clarifying, type_selection

⏳ LOADING MESSAGE (with spinner)
    • Spinner animation
    • Stays visible (doesn't auto-dismiss)
    • Used for: generating, generating_json

✅ SUCCESS MESSAGE (Green)
    • Green check icon
    • Auto-dismisses after 3 seconds
    • Used for: analysis_complete, code_generated, completed, etc.

⚠️  WARNING MESSAGE (Orange)
    • Orange warning icon
    • Auto-dismisses after 3 seconds
    • Used for: refining, fallback_fix

❌ ERROR MESSAGE (Red)
    • Red X icon
    • Stays visible (user must dismiss)
    • Shows error details
    • Used for: error status

🔇 SILENT (No UI Message)
    • No notification shown
    • Only console logging
    • System continues silently
    • Used for: waiting, validating, rendering, rendered

COMMON QUESTIONS
─────────────────────────────────────────────────────────────────────────────

Q: Why doesn't "waiting" show a message?
A: It occurs every 60 seconds during LLM processing. Showing a message would
   spam the UI. Console log is for monitoring/debugging only.

Q: Why don't "validating" and "rendering" show messages?
A: These are fast, silent operations that don't require user action. The UI
   updates automatically when done (code appears, SVG renders).

Q: What if the status is not in the list?
A: Falls through to default case (no action taken). Status flows through the
   main switch statement at DiagramWizard.tsx:232-345

Q: How long does each phase typically take?
A:
  - Analysis: 5-30 seconds
  - Clarification: User dependent
  - Generation: 10-60 seconds
  - Validation: 1-5 seconds
  - Rendering: <1 second

Q: What if I see multiple "waiting" messages in console?
A: Normal! That's the "waiting" status sent every 3 seconds while LLM is
   processing. It means the system is working correctly and provides frequent
   UI updates about processing progress.
